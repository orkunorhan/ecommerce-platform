# Ecommerce Platform

A production-inspired full-stack e-commerce application built with modern web technologies and software engineering best practices.

## 📖 Overview

This repository contains my final capstone project for the Workintech Full-Stack Developer Program.

The goal of this project is to build a scalable and maintainable e-commerce platform by applying modern frontend and backend development practices. The application is being developed incrementally using a Kanban workflow, feature branches, and Conventional Commits to simulate a professional software development lifecycle.

🌐 Live Demo: https://orkunorhan-ecommerce.vercel.app/

## ⚙️ Getting Started

### Clone the repository

```bash
git clone https://github.com/orkunorhan/ecommerce-platform.git
cd ecommerce-platform
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```
